# AI 使用记录（AI Usage Log）

> **本文件是实验要求的正式交付物**，记录每一次使用 AI Agent 生成规格、UML、代码或测试的过程。
> 格式依据实验文档《Agent 提示词手册》第 20 节模板。
>
> **与 `worklog.md` 的分工**：
> - 本文件：面向验收的 AI 使用摘要，格式规范、内容简练
> - `worklog.md`：过程性时序记录，含内部推理、冲突裁定、待确认项
>
> **使用的 Agent 工具**：WorkBuddy（基于 CodeBuddy / Claude 的编码 Agent）
> **使用方式**：Agent 起草 → 人类审查 → 人类拍板 → Agent 修订，逐步骤交互推进

---
