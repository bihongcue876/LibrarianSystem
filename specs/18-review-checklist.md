## 1. 审查准备工作

### 1.1 建议的查看顺序

按依赖关系自底向上核对，避免被上游错误误导：

```
① 需求规格 (02)  →  ② 用例文本 (03)  →  ③ 用例图 (04)
                        ↓
④ 领域模型 (05)  →  ⑤ 类图 (06)  →  ⑥ 架构 (07)  →  ⑦ 包图 (08)  →  ⑧ 数据库 (13)
```

### 1.2 命令准备

```bash
# 查看实验一全部改动（实验文档第十八节指定）
git diff HEAD~10..HEAD

# 查看文件清单
git ls-files specs/

# 查看提交历史
git log --oneline

# 检查标签（打 baseline 前应为空）
git tag -l
```

### 1.3 机械验证命令

以下命令用于**自动发现**问题，先跑一遍可大幅减少人工工作量：

```bash
# 【检查 1】领域模型/类图是否混入设计类（对应 MOD-01）
grep -n "Controller\|Repository\|DTO\|Mapper" specs/05-domain-model.md specs/06-domain-class-diagram.md
# 期望：仅在"不包含""不含"等否定语境的说明句中命中，无实质设计类

# 【检查 2】领域层是否引入框架（对应 ARC-02，实验二适用）
grep -rn "sqlalchemy\|fastapi" backend/app/domain/
# 期望：0 命中

# 【检查 3】Router 是否直接查库（对应 ARC-01，实验二适用）
grep -n "db.query\|session.query\|select(" backend/app/presentation/routers/
# 期望：0 命中

# 【检查 4】规则数值是否硬编码（对应 BR-049，实验二适用）
grep -rn "== 5\|== 10\|== 15\|== 20\|0\.2\|0\.5\|1\.0" backend/app/domain/policies/
# 期望：0 命中（规则必须查库）

# 【检查 5】Mermaid 代码块数量与配对完整性（对应 AI-04）

# 【检查 6】初始化脚本是否硬编码密码（对应 SEC-05）
grep -n "password\s*=\s*['\"]" backend/scripts/init_db.py
# 期望：0 命中（密码须从参数/环境变量读入）
